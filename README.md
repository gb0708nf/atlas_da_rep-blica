# 🇧🇷 Atlas da República

O Atlas da República é uma plataforma educacional interativa dedicada à História da República Brasileira. O projeto reúne informações sobre presidentes, constituições, períodos históricos e indicadores relevantes, oferecendo uma experiência dinâmica para estudantes, professores e interessados na história política do Brasil.

## 📚 Objetivo

Facilitar o acesso ao conhecimento histórico por meio de uma interface moderna e intuitiva, reunindo em um único ambiente conteúdos fundamentais sobre a República Brasileira.

## ✨ Funcionalidades

- Linha do tempo da República Brasileira
- Informações sobre presidentes da República
- Consulta às constituições brasileiras
- Dados e indicadores históricos
- Navegação interativa e responsiva
- Interface amigável para fins educacionais

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub Pages
